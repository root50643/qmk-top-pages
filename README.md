# qmk.top mirror

This repository contains a static copy of [qmk.top](https://qmk.top/) for GitHub Pages. The V4 driver includes its statically referenced JavaScript chunks and assets. Brand images that the source server did not provide use a generic fallback.

Connect a supported device in a WebHID-capable browser and grant the browser access to it. The original app's online APIs remain external services; GitHub Pages cannot host those backends or change their CORS policies, so online version checks and firmware downloads may not work from this origin.
